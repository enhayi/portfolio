Project Overview

This High-Frequency Trading (HFT) Simulator is a Python-based application built with Streamlit that allows users to experiment with algorithmic trading strategies using both historical and live market data. The simulator provides a realistic environment for testing mean-reversion, momentum, and arbitrage strategies while visualizing trade execution, profit & loss (PnL), and market movements in real time.

Multi-Source Data Integration

Historical Data: Fetch minute-level stock data from Yahoo Finance or upload custom CSV datasets.

Live Market Data: Connect to Alpha Vantage or Finnhub APIs for real-time price streaming.

Customizable Trading Strategies

Mean Reversion: Trade based on deviations from moving averages (Bollinger Bands).

Momentum Trading: Execute trades based on short-term price trends.

Statistical Arbitrage: Exploit price differences against a reference value.

Real-Time Visualization

Interactive Plotly charts showing price movements, trading signals, and PnL.

Trade execution markers (buy/sell signals) overlaid on price charts.

Performance metrics (positions, trade history, profit tracking).
