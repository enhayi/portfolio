Project Overview

The Portfolio Optimizer is a data-driven web application that helps users build efficient investment portfolios using real-time financial data. Leveraging Modern Portfolio Theory, the app calculates optimal asset allocations by maximising the Sharpe ratio—balancing expected return against risk. It fetches live stock prices via the Yahoo Finance API, computes historical returns and volatility, and performs constrained optimisation to determine the most balanced portfolio. The tool also includes intuitive visualisations such as pie charts for asset allocation and efficient frontier plots to illustrate risk-return trade-offs.

Built with Python and Streamlit, the project combines financial modelling with interactive web design to offer an accessible, browser-based experience for both beginner and advanced users. Users can select custom stock tickers, define time ranges, and instantly generate portfolio recommendations, performance metrics, and historical backtesting results. Whether used for educational purposes, personal investing, or showcasing quantitative skills, the Portfolio Optimizer highlights the practical application of finance, data science, and web technology in one cohesive project.
